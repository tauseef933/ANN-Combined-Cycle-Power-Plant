# ANN-Combined-Cycle-Power-Plant
Predicts energy output (EP) of a CCPP using an Artificial Neural Network (ANN).

Model: ANN built with TensorFlow/Keras.

Dataset: UCI ML dataset (9568 samples) with temperature, pressure, humidity, and vacuum features.

Metrics: Achieves R² ≈ 0.98 (strong predictive accuracy).

Use Case: Optimizes power plant efficiency and load forecasting.

🔧 Tech Stack
Python, TensorFlow, Scikit-learn, Pandas
